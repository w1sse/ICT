ADDITIONAL PROJECT MODULE

Check before you click.

These demo tools look for a few common warning signs in a website address or IP address. They do not connect to live threat databases.

⚠️
Important limitation

A result with no obvious warning signs does not mean an address is safe. Do not open a suspicious link just to test it. Checks run in your browser and do not send the entered address or IP to a server.

🔗

Website & link check

Review a URL as text. This page will not open it.

Do not enter private account links.
⌘

IP address format

Check IPv4 format and a few special ranges.

This does not check ownership or reputation. IPv6 is not supported.

Identify a possible threat type

What the scanner can and cannot do

✓

It can

  • Check basic URL formatting.
  • Flag a few suspicious-looking patterns.
  • Validate IPv4 format.
  • Explain common threat categories.
×

It cannot

  • Confirm a site is malicious or safe.
  • Look up current threat reports or IP ownership.
  • Replace antivirus or professional analysis.
🔒

For real-time checks

A production version needs a secure backend and trusted threat-intelligence services, with clear privacy information.
